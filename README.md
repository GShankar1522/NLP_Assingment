# NLP_Assingment
Sentiment analysis project <br>
Sentiment Analysis Using TextBlob <br>
Overview <br>
This Python script performs sentiment analysis on a given text input using the TextBlob library. It analyzes the sentiment polarity and categorizes it into five sentiment <br> categories: <br>

Strongly Positive 😊 <br>
Positive 🙂 <br>
Neutral 😐 <br>
Negative 🙁 <br>
Strongly Negative 😡 <br>
Features <br>
Uses TextBlob for sentiment analysis. <br>
Categorizes sentiment based on polarity score. <br>
Assigns an emoji to each sentiment category for better visualization. <br>
Installation <br>
Ensure you have Python installed, then install the required dependency: <br>
pip install textblob<br>
Usage<br>
Clone this repository or copy the script.<br>
Run the Python script with a sample input text.<br>
OUTPUT:<br>
Input Text: I am G Shankar from 3rd year CSE AIML. I have basic skills in programming and machine learning. I am interested in doing projects and learning new things. Thank you!<br>
Sentiment Score: 0.225<br>
Sentiment Category: Positive 🙂 <br>
Requirements<br>
Before running the script, ensure you have:<br>

Python 3.x installed<br>
TextBlob library installed<br>
