# NLP_Assingment
Sentiment analysis project <br>
Sentiment Analysis Using TextBlob
Overview
This Python script performs sentiment analysis on a given text input using the TextBlob library. It analyzes the sentiment polarity and categorizes it into five sentiment categories:

Strongly Positive 😊
Positive 🙂
Neutral 😐
Negative 🙁
Strongly Negative 😡
Features
Uses TextBlob for sentiment analysis.
Categorizes sentiment based on polarity score.
Assigns an emoji to each sentiment category for better visualization.
Installation
Ensure you have Python installed, then install the required dependency: 
pip install textblob
Usage
Clone this repository or copy the script.
Run the Python script with a sample input text.
OUTPUT:
Input Text: I am G Shankar from 3rd year CSE AIML. I have basic skills in programming and machine learning. I am interested in doing projects and learning new things. Thank you!
Sentiment Score: 0.225
Sentiment Category: Positive 🙂 <br>
Requirements
Before running the script, ensure you have:

Python 3.x installed
TextBlob library installed
